## Package and publish

1. Review source, tests, docs and all raster images; record exact test outcomes.
2. Commit the reviewed state and use an annotated semantic-version tag `v2.4.0`.
3. Export that exact tag with `git archive --format=zip --prefix=travel-guide-pwa-builder/`; keep the archive outside the tracked tree.
4. List/test the ZIP and publish a SHA-256 checksum alongside it.
5. Push the commit/tag to the existing public repository, then create a GitHub Release with the ZIP, checksum and human-readable notes.
6. Install from that release snapshot and compare file hashes. The install must not remove unrelated skills or overwrite unknown local edits.

This document records source-level verification. The GitHub Release page is the authoritative publication receipt; a local ZIP is not a published release.
